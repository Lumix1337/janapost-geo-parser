# Jana Address — Интеллектуальный разбор адресов JanaPost

Решение кейса **Jana Address** хакатона **Jana Post × Terricon Valley**.

Система выполняет автоматический оффлайн-разбор неструктурированных адресных строк доставки на 11 нормализованных полей, восстанавливает недостающие справочные поля (район, область, тип улицы) по собственному гео-справочнику Казахстана (КАТО + OpenStreetMap) и рассчитывает показатель уверенности (`confidence`).

---

## 🚀 Быстрый запуск (Docker / Podman)

Запуск всего решения (REST API + Web UI) осуществляется **одной командой**:

```bash
docker compose up --build
```
или с использованием Podman:
```bash
podman compose up --build
```

После старта сервис доступен по адресу:
- **Веб-интерфейс оператора**: [http://localhost:8000](http://localhost:8000)
- **REST API Healthcheck**: [http://localhost:8000/api/health](http://localhost:8000/api/health)

> **Автономность**: Сервис полностью автономен, упакован в образ и работает **без доступа в интернет** (в оффлайн-режиме для жюри).

## 📡 REST API Спецификация

### 1. Пакетная обработка адресов (основной метод для жюри)
- **Endpoint**: `POST /api/batch`
- **Content-Type**: `application/json`

**Запрос (Request Body)**:
```json
[
  {
    "id": "rec_00417",
    "raw_address": "город Алматы/Алматы қаласы, Мкр Аксай 3а, 59, кв 70"
  }
]
```

**Ответ (Response Body)**:
```json
[
  {
    "id": "rec_00417",
    "raw_address": "город Алматы/Алматы қаласы, Мкр Аксай 3а, 59, кв 70",
    "province": "Алматы",
    "city": "Алматы",
    "district": "Ауэзовский",
    "living_area": null,
    "street_type": "микрорайон",
    "street_name": "Аксай 3а",
    "house": "59",
    "apartment": "70",
    "entrance": null,
    "floor": null,
    "landmark": null,
    "confidence": 0.91
  }
]
```

### 2. Одиночный разбор адреса
- **Endpoint**: `POST /api/parse`
- **Request**: `{ "id": "rec_001", "raw_address": "Туран 55/6 магазин береке 4подьезд 9этаж" }`
- **Response**: одиночный JSON-объект формата `AddressOutput`.

### 3. Интерактивная документация Swagger / OpenAPI UI
- **Swagger UI**: `http://localhost:8000/swagger-ui.html`
- **OpenAPI JSON Spec**: `http://localhost:8000/api-docs`
Интерактивная консоль для тестирования всех REST-методов прямо в браузере с готовыми примерами запросов и типизацией схем.

## 💻 Веб-интерфейс оператора

Интерфейс доступен в браузере по адресу `http://localhost:8000` и включает:
1. **Экспресс-разбор**: поле быстрого ввода для интерактивной проверки произвольной строки с моментальной подсветкой полей.
2. **Drag & Drop пакетная загрузка**: загрузка `.json` файлов (например, `sample_input.json`).
3. **Прямой переход к Swagger**: кнопка `📖 Swagger API` в шапке панели.
4. **Виртуальная пагинация**: плавная работа с большими выборками (50 строк на страницу, фильтрация без фризов).
5. **Таблица разбора с подсветкой уверенности**:
   - Зеленый бейдж ($\ge 85\%$) — высокая уверенность.
   - Желтый бейдж ($65\% - 85\%$) — средняя уверенность.
   - Красный бейдж ($< 65\%$) — требуется внимание оператора.
6. **Инлайн-редактирование**: двойной клик по ячейке таблицы позволяет скорректировать любое значение прямо в браузере.
7. **Экспорт результата**: выгрузка итогового `.json` файла в точном соответствии со спецификацией жюри.

## 🏛 Архитектура решения

Решение построено на **Java 21** и **Spring Boot 3**:
- **TextNormalizer**: очистка невидимых unicode-символов (`\u200B`), разбор билингвальных склеек (`/Алматы қаласы`), разделение слитных написаний (`66квартал`, `12дом`, `4подьезд`, `9этаж`).
- **SlotExtractor**: детерминированное извлечение дома, квартиры, подъезда, этажа и ориентиров.
- **GeoMatcher & KatoRepository**: сопоставление населенного пункта с 20 регионами Казахстана и обогащение недостающих районов (`district`) по связке `город + улица/микрорайон`.
- **ConfidenceScorer**: расчет уверенности разбора на основе полноты ключевых адресных атрибутов.
- **Производительность**: параллельная обработка потоков (`Parallel Streams`), 1000 записей разбираются всего за **~0.05 секунды** (более 16 000 записей в секунду, в 5000 раз быстрее лимита жюри в 300 секунд).

## 📱 Интеграция в мобильное приложение JanaPost

Ядро парсера на чистой Java может быть напрямую подключено к мобильному приложению `MyApplication` (JanaPost Android) на экране профиля и оформления заказа, предоставляя пользователям интеллектуальный ввод адреса в одну строку с мгновенным автозаполнением формы доставки.
